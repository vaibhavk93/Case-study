# Case Study Mastery

An interactive playbook for case interviews, covering both product
management and management consulting formats.

## Read it online

- **[Interactive Guide](https://vaibhavk93.github.io/Case-study/)**
  — 50 chapters, 12 fully worked cases, 75 practice cases, 7 tests,
  and a spaced-repetition recall deck
- **[Practice Workbook](https://vaibhavk93.github.io/Case-study/workbook.html)**
  — 87 prompts with working space and scorecards
- **[Research Sources](https://vaibhavk93.github.io/Case-study/sources.html)**
  — 54 sources across 11 topics, each with verification status

## What it covers

A universal method for working a case end to end — structure the
problem, decompose it, find the root cause, generate options, pick
metrics, and defend the recommendation. Built around MECE as a working
tool rather than a slogan, with 16 case-type chapters covering
profitability, market entry, product design, growth, pricing, market
sizing, prioritisation, metrics diagnosis, and others.

The recall material is organised around retrieval practice and spaced
repetition rather than rereading, following the evidence on which study
techniques actually transfer.

## On the numbers

Every figure in a worked example is either labelled as a public
approximation or explicitly flagged as invented for the arithmetic.
Where a number is made up, the text says so. None of the worked cases
should be read as reporting a real company's actual financials.

## Offline use

Each page is a single self-contained HTML file with no external scripts
or stylesheets. Save one to disk and it works without a network
connection. Quiz progress and recall-deck scheduling are stored in your
browser's local storage, so they stay on the device you study on.
